# Developer Resume / GitHub Pages Portfolio

Responsive one-page portfolio built with plain HTML, CSS and JavaScript.

## Personalize it
1. Replace `YOUR NAME` in `index.html` with your name.
2. Edit the `profile` object in `script.js` with your real name, email, GitHub URL and LinkedIn URL.
3. Replace sample project repository links with your real public repositories.
4. Add your real resume as `resume.pdf` in this folder, or remove the Resume PDF link until you have one.
5. Only list skills and projects you can honestly explain in an interview.

## Publish with GitHub Pages
1. Create a repository named `yourusername.github.io` (replace with your GitHub username).
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository root.
3. Go to **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. After deployment, your site should be at `https://yourusername.github.io/`.

## Accuracy notes
Skills are deliberately described as learning/practising rather than expert-level. The Northstar e-commerce homepage is a front-end demo. DSA and Java projects are suggested portfolio entries: link them only after creating your own repositories. This site does not claim professional software-development experience.
